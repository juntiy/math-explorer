# 🚀 奇妙数学乐园 · Math Explorer

> 一个让小学生 **一眼看懂、动态理解、真正爱上数学** 的网页。用动画、积木、数轴和 **3D 立体图形**，把抽象的数学概念变成看得见、动得起来的东西。

🌐 **在线体验**：https://juntiy.github.io/math-explorer/

---

## ✨ 它讲什么（8 大展区 · 5 站「发现之旅」）

沿一条「从易到难」的发现之路展开：① 数字诞生 → ② 加减乘除 → ③ 平方·根号 → ④ 几何·面积 → ⑤ 奇偶·数论。每个概念都用**具象的物理直觉 + 动态动画**讲清楚：

| 展区 | 看点（动态 / 3D） |
|------|------|
| 🔢 **数字的产生** | 🍎 苹果掉进 3D 框里“凝结”成数字；每满 10 个自动熔成 1 枚「十位金币」，直观体验**逢十进一**。 |
| ➕ **加减法** | 积木“合起来 / 飞走”；点「看小兔子跳一跳」，**🐰 在 3D 数轴上一步步跳到结果**。 |
| ✖️ **乘除法** | 点「线→面」把阵列**立体倾斜成一张“面”**（乘法=把线拉伸成面）；除法用**🎂 蛋糕激光切分**成等份。 |
| 🔁 **奇数偶数** | 两个两个配对：偶数刚好配完，奇数的**落单者会发光摇晃**。 |
| ⬛ **平方** | 点「线段变正方形」：**一条线段向上拉伸成 n×n 正方形**，看懂平方=线变面。 |
| √ **根号** | 平方的反动作；新增**🟫 泥块捏塑小游戏**——已知面积，拖动捏出边长，刚好拼成正方形即胜利。 |
| ▦ **面积** | 单位小方块铺满长方形，面积 = 长 × 宽。 |
| 📐 **几何图形** | 平面多边形（边/角）+ **会旋转的 3D 立体图形**；新增**平行四边形剪拼成长方形**、**圆面积扇形极限展开成近似长方形（S=πr²）**动画。 |

每弄懂一个展区，右上角的 ⭐ 就多一颗，集满 8 颗就是「数学小探险家」。

## 🛠 技术栈

- **纯原生 HTML + CSS + JavaScript**，单文件 `index.html`，**零运行时依赖、可离线打开**。
- 3D 立体图形用 **CSS 3D 变换**（`transform-style: preserve-3d` + `perspective`）实现，无需任何 3D 库。
- 数轴、方块、网格等全部用 DOM / Canvas 动态生成。
- 字体：Google Fonts 的 **ZCOOL KuaiLe（站酷快乐体）** + **Baloo 2**（均为开源字体，SIL OFL）。

> 想做得更炫？后续可把 3D 部分升级为 [Three.js](https://threejs.org/)（真实 WebGL 渲染），或把孩子的进度存到云端做多设备同步。

## 🚀 本地运行

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge / 平板端，体验最佳）。

若想用本地服务器预览：

```bash
# 任选其一
python -m http.server 8080      # 然后访问 http://localhost:8080
# 或
npx serve .
```

## ☁️ 部署到 GitHub Pages

本仓库已配置 GitHub Pages（main 分支根目录）。发布方式：

1. 把 `index.html` 推到 `main` 分支；
2. 在仓库 **Settings → Pages** 选择 `Deploy from a branch` → `main` / `(root)`；
3. 等待 1 分钟左右，站点即在 `https://<用户名>.github.io/math-explorer/` 生效。
